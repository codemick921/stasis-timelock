How the lock works

01

Connect

On Seeker, connect through the Seed Vault wallet so signing happens in secure hardware. On desktop, use Phantom or Solflare.

02

Lock

Your USDC moves into a vault owned by a program PDA. The unlock timestamp is written on-chain and cannot be edited.

03

Withdraw

After the timestamp passes, one signature sends the USDC back to the same wallet and closes the vault, returning rent.

What the program can and cannot do

Release the balance to the recorded owner after the unlock time.
Close the vault and return rent to the owner.
Move funds before the unlock timestamp.
Send funds to any wallet other than the recorded owner.
Change the unlock date after the lock is created.
Bypass the lock through an admin or upgrade path.

Devnet build. The program is deployed with an upgrade authority while it is being tested; a mainnet release should revoke it after review. Verify the program address before locking real funds.
