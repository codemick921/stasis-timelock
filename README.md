# Stasis — devnet demo

Static build of a non-custodial USDC time lock on Solana.

- Program: `ATNeGq8Dkn8Xxjq9XELziu6yaLg1WA7kRrjNjas6yhjn` (devnet)
- Lock funds until a timestamp; no admin, no early exit.
- Wallet: Seeker Seed Vault via Mobile Wallet Adapter, or Phantom/Solflare on desktop.
- Set your wallet to **Devnet** before signing.

This repository contains the compiled static site only.
